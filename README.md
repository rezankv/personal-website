# Personal Website

This is a statically generated personal website built with **Next.js** and **TypeScript**, where I showcase the projects I've worked on and share my thoughts and experiences as a web developer.

All content is written in **MDX** and managed using **Contentlayer**, making it easy to write and maintain blog posts and project pages.

## ✨ Features

- ⚡️ Fast static site powered by Next.js (App Router)
- 📄 Content in MDX format
- 🧠 Typed content with Contentlayer
- 🧩 Fully typed and built with TypeScript
- 📱 Responsive design for all devices
- 🌙 Light/Dark mode support
- 🧭 SEO-friendly routing and meta tags

## 🛠 Tech Stack

- [Next.js](https://nextjs.org/)  
- [TypeScript](https://www.typescriptlang.org/)
- [Contentlayer](https://www.contentlayer.dev/)
- [MDX](https://mdxjs.com/)
- [Tailwind CSS](https://tailwindcss.com/)
