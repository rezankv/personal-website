## ساخت پنل مدیریت از صفر با TailwindCSS , HTML و JQuery (یه تجربه جدید!)

یک روز مشغول نصب تم روی ترمینالم بودم که یکی از کارفرماهای قبلی دوباره پیام داد و گفت:  
«یه پنل مدیریت می‌خوام، ولی بدون هیچ فریم‌ورکی. صفحات خام رو تحویل بده، من سمت سرور رندر می‌کنم.»

عادت داشتم برای پروژه‌های این مدلی از ابزارهایی مثل <a href='https://nextjs.org/' target='_blank'>Next.js</a> استفاده کنم.  
اما این بار ماجرا فرق می‌کرد.
همون‌جا بود که فهمیدم قراره تجربه جدیدی رو رقم بزنم.  
چون تا حالا پروژه‌ای مثل این که تقریبا بزرگ بود رو **بدون ابزارهای کمکی** و **از صفر مطلق** شروع نکرده بودم.

منم که عاشق تجربیات جدیدم٬ تصمیم گرفتم قبول کنم و کارو شروع کردم.

## 👨🏻‍💻 چیکار کردم؟

تقریبا دو سه روز رو صرف پیدا کردن یه معماری مناسب کردم. چون بنظر من اگر معماری یه پروژه درست باشه، می‌تونه به راحتی قابل نگهداری و توسعه پذیر باشه.  
با کمک <a href='https://tailwindcss.com/' target='_blank'>TailwindCSS</a> رنگ ها٬ تایپوگرافی٬ فاصله ها و سایر موارد مربوط به دیزاین رو ستاپ کردم.  
برای پیاده سازی قسمت های تعاملی تصمیم گرفتم از <a href='https://jquery.com/' target='_blank'>JQuery</a> استفاده کنم چون میخواستم تا جایی که امکانش هست و اجازه دارم چیزی رو دستی پیاده سازی نکنم تا در وقت صرفه جویی بشه.  
برای افزایش قابلیت استفاده مجدد(reusability) و بهبود <a href='https://en.wikipedia.org/wiki/Developer_Experience' target='_blank'>DX</a> از ابزار <a href='https://handlebarsjs.com/' target='_blank'>handlebars</a> استفاده کردم.  
برای باندل کردن پروژه هم از <a href='https://vite.dev/' target='_blank'>vite</a> استفاده کردم و چند ساعتی مشغول ستاپ کردنش بودم هم برای توسعه و هم برای بیلد نهایی(production).  

موارد پایه ای رو که تنظیم کردم شروع به ساخت کامپوننت ها کردم و صفحات که مثل یه پازل بودن کم‌کم تکمیل شدن.


## ⚡ بهینه‌سازی و پرفورمنس

برای اینکه سرعت لود بالابره و مصرف منابع به حداقل برسه این کار هارو انجام دادم:

- استفاده از تگ‌های HTML درست در جای مناسب
- حذف CSS های اضافه
- کاهش حجم تصاویر
- پاک کردن import های اضافه


## 🔥 آخرش چی شد؟

خروجی رو خیلی دوست داشتم. یک پنل مدیریت  تمیز و قابل نگهداری که هم سریعه و هم تا جای ممکن بهینه شده.  
از لینک زیر میتونی دمو پروژه رو ببینی😍
