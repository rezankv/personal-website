Arrays are one of the most fundamental data structures in JavaScript and are widely used in programming. In job interviews, you'll often be asked how you manage data using array methods. Let's explore the most important array methods.

### push

- **Functionality:** Adds one or more elements to the end of an array
- **Input:** One or more values to add
- **Output:** The new length of the array after adding elements
- **Modifies Original Array:** Yes

Example:

<CodeBlock title="Javascript" raw={`let numbers = [1, 2, 3];
let newLength = numbers.push(4, 5);
console.log(numbers); // [1, 2, 3, 4, 5]
console.log(newLength); // 5`}>

```js
let numbers = [1, 2, 3];
let newLength = numbers.push(4, 5);
console.log(numbers); // [1, 2, 3, 4, 5]
console.log(newLength); // 5
```

</CodeBlock>

### pop

- **Functionality:** Removes the last element from an array and returns it
- **Input:** None
- **Output:** The removed element
- **Modifies Original Array:** Yes

Example:

<CodeBlock title="Javascript" raw={`let fruits = ["apple", "banana", "orange"];
let lastFruit = fruits.pop();
console.log(fruits); // ["apple", "banana"]
console.log(lastFruit); // "orange"`}>

```js
let fruits = ["apple", "banana", "orange"];
let lastFruit = fruits.pop();
console.log(fruits); // ["apple", "banana"]
console.log(lastFruit); // "orange"
```

</CodeBlock>

### shift

- **Functionality:** Removes the first element from an array and returns it
- **Input:** None
- **Output:** The removed element
- **Modifies Original Array:** Yes

Example:

<CodeBlock title="Javascript" raw={`let queue = [10, 20, 30];
let first = queue.shift();
console.log(queue); // [20, 30]
console.log(first); // 10`}>

```js
let queue = [10, 20, 30];
let first = queue.shift();
console.log(queue); // [20, 30]
console.log(first); // 10
```

</CodeBlock>

### unshift

- **Functionality:** Adds one or more elements to the beginning of an array
- **Input:** One or more values
- **Output:** The new length of the array
- **Modifies Original Array:** Yes

Example:

<CodeBlock title="Javascript" raw={`let numbers = [2, 3];
numbers.unshift(0, 1);
console.log(numbers); // [0, 1, 2, 3]`}>

```js
let numbers = [2, 3];
numbers.unshift(0, 1);
console.log(numbers); // [0, 1, 2, 3]
```

</CodeBlock>

### slice

- **Functionality:** Extracts a section of an array and returns a new array
- **Input:** Start index, end index (optional, end element not included)
- **Output:** New array
- **Modifies Original Array:** No

Example:

<CodeBlock title="Javascript" raw={`let arr = [1, 2, 3, 4, 5];
let part = arr.slice(1, 4);
console.log(part); // [2, 3, 4]
console.log(arr); // [1, 2, 3, 4, 5]`}>

```js
let arr = [1, 2, 3, 4, 5];
let part = arr.slice(1, 4);
console.log(part); // [2, 3, 4]
console.log(arr); // [1, 2, 3, 4, 5]
```

</CodeBlock>

### splice

- **Functionality:** Adds, removes, or replaces elements in an array
- **Input:** Start index, deleteCount, items…
- **Output:** Array containing removed elements
- **Modifies Original Array:** Yes

Examples:

<CodeBlock title="Javascript" raw={`
let arr = [1, 2, 3, 4, 5];
// Removal
let removed = arr.splice(2, 2);
console.log(arr); // [1, 2, 5]
console.log(removed); // [3, 4]

// Adding
arr.splice(2, 0, 6, 7);
console.log(arr); // [1, 2, 6, 7, 5]

// Replacement
arr.splice(1, 2, 8, 9);
console.log(arr); // [1, 8, 9, 7, 5]
`}>

```js
let arr = [1, 2, 3, 4, 5];
// Removal
let removed = arr.splice(2, 2);
console.log(arr); // [1, 2, 5]
console.log(removed); // [3, 4]

// Adding
arr.splice(2, 0, 6, 7);
console.log(arr); // [1, 2, 6, 7, 5]

// Replacement
arr.splice(1, 2, 8, 9);
console.log(arr); // [1, 8, 9, 7, 5]
```

</CodeBlock>



### forEach

- **Functionality:** Executes a callback function for each array element
- **Input:** Callback function with parameters (element, index, array)
- **Output:** None (undefined)
- **Modifies Original Array:** No (unless callback modifies it)

Example:

<CodeBlock title="Javascript" raw={`let arr = [1, 2, 3];
arr.forEach(num => console.log(num * 2));
// 2, 4, 6`}>

```js
let arr = [1, 2, 3];
arr.forEach(num => console.log(num * 2));
// 2, 4, 6
```

</CodeBlock>

### map

- **Functionality:** Creates a new array with the results of calling a callback on every element
- **Input:** Callback function with parameters (element, index, array)
- **Output:** New array
- **Modifies Original Array:** No

Example:

<CodeBlock title="Javascript" raw={`let numbers = [1, 2, 3];
let squared = numbers.map(n => n \* n);
console.log(squared); // [1, 4, 9]
console.log(numbers); // [1, 2, 3]`}>

```js
let numbers = [1, 2, 3];
let squared = numbers.map(n => n \* n);
console.log(squared); // [1, 4, 9]
console.log(numbers); // [1, 2, 3]
```

</CodeBlock>

### filter

- **Functionality:** Creates a new array with elements that pass a test implemented by the callback
- **Input:** Callback function (returns true/false)
- **Output:** New array
- **Modifies Original Array:** No

Example:

<CodeBlock title="Javascript" raw={`let nums = [1, 2, 3, 4, 5];
let even = nums.filter(n => n % 2 === 0);
console.log(even); // [2, 4]`}>

```js
let nums = [1, 2, 3, 4, 5];
let even = nums.filter((n) => n % 2 === 0);
console.log(even); // [2, 4]
```

</CodeBlock>

### reduce

- **Functionality:** Reduces an array to a single value by executing a callback on each element
- **Input:** Callback(accumulator, currentValue, index, array), initialValue (optional)
- **Output:** Single value (number, string, object…)
- **Modifies Original Array:** No

Example:

<CodeBlock title="Javascript" raw={`let nums = [1, 2, 3, 4];
let sum = nums.reduce((acc, n) => acc + n, 0);
console.log(sum); // 10`}>

```js
let nums = [1, 2, 3, 4];
let sum = nums.reduce((acc, n) => acc + n, 0);
console.log(sum); // 10
```

</CodeBlock>

### find

- **Functionality:** Returns the first element that satisfies the callback condition
- **Input:** Callback function (returns true/false)
- **Output:** Found element or undefined
- **Modifies Original Array:** No

Example:

<CodeBlock title="Javascript" raw={`let users = [{id:1,name:"Ali"}, {id:2,name:"Sara"}];
let user = users.find(u => u.id === 2);
console.log(user); // {id:2, name:"Sara"}`}>

```js
let users = [
  { id: 1, name: "Ali" },
  { id: 2, name: "Sara" },
];
let user = users.find((u) => u.id === 2);
console.log(user); // {id:2, name:"Sara"}
```

</CodeBlock>

### includes

- **Functionality:** Checks if an array contains a specific element
- **Input:** Value to check, start index (optional)
- **Output:** true/false
- **Modifies Original Array:** No

Example:

<CodeBlock title="Javascript" raw={`let fruits = ["apple","banana"];
console.log(fruits.includes("banana")); // true
console.log(fruits.includes("orange")); // false`}>

```js
let fruits = ["apple", "banana"];
console.log(fruits.includes("banana")); // true
console.log(fruits.includes("orange")); // false
```

</CodeBlock>

### sort

- **Functionality:** Sorts the elements of an array
- **Input:** Comparison callback (optional)
- **Output:** Sorted array
- **Modifies Original Array:** Yes

Example:

<CodeBlock title="Javascript" raw={`let nums = [3, 1, 4, 2];
nums.sort((a,b) => a-b);
console.log(nums); // [1,2,3,4]`}>

```js
let nums = [3, 1, 4, 2];
nums.sort((a, b) => a - b);
console.log(nums); // [1,2,3,4]
```

</CodeBlock>

### reverse

- **Functionality:** Reverses the order of elements in an array
- **Input:** None
- **Output:** Reversed array
- **Modifies Original Array:** Yes

Example:

<CodeBlock title="Javascript" raw={`let arr = [1,2,3];
arr.reverse();
console.log(arr); // [3,2,1]`}>

```js
let arr = [1, 2, 3];
arr.reverse();
console.log(arr); // [3,2,1]
```

</CodeBlock>

### indexOf

- **Functionality:** Returns the first index at which a given element can be found
- **Input:** Value to find, start index (optional)
- **Output:** Index of element or -1 if not found
- **Modifies Original Array:** No

Example:

<CodeBlock title="Javascript" raw={`let fruits = ["apple", "banana", "orange", "banana"];
console.log(fruits.indexOf("banana")); // 1
console.log(fruits.indexOf("grape")); // -1`}>

```js
let fruits = ["apple", "banana", "orange", "banana"];
console.log(fruits.indexOf("banana")); // 1
console.log(fruits.indexOf("grape")); // -1
```

</CodeBlock>

### lastIndexOf

- **Functionality:** Returns the last index at which a given element can be found
- **Input:** Value to find, start index (optional)
- **Output:** Index of element or -1
- **Modifies Original Array:** No

Example:

<CodeBlock title="Javascript" raw={`let fruits = ["apple", "banana", "orange", "banana"];
console.log(fruits.lastIndexOf("banana")); // 3`}>

```js
let fruits = ["apple", "banana", "orange", "banana"];
console.log(fruits.lastIndexOf("banana")); // 3
```

</CodeBlock>

### every

- **Functionality:** Tests whether all elements pass the callback condition
- **Input:** Callback (returns true/false)
- **Output:** true/false
- **Modifies Original Array:** No

Example:

<CodeBlock title="Javascript" raw={`let nums = [2, 4, 6];
console.log(nums.every(n => n % 2 === 0)); // true`}>

```js
let nums = [2, 4, 6];
console.log(nums.every((n) => n % 2 === 0)); // true
```

</CodeBlock>

### findIndex

- **Functionality:** Returns the index of the first element that satisfies the callback condition
- **Input:** Callback (returns true/false)
- **Output:** Index or -1
- **Modifies Original Array:** No

Example:

<CodeBlock title="Javascript" raw={`let users = [{id:1},{id:2},{id:3}];
let idx = users.findIndex(u => u.id === 2);
console.log(idx); // 1`}>

```js
let users = [{ id: 1 }, { id: 2 }, { id: 3 }];
let idx = users.findIndex((u) => u.id === 2);
console.log(idx); // 1
```
</CodeBlock>

### concat

- **Functionality:** Merges two or more arrays and returns a new array
- **Input:** One or more arrays or values
- **Output:** New array
- **Modifies Original Array:** No

Example:

<CodeBlock title="Javascript" raw={`let arr1 = [1,2];
let arr2 = [3,4];
let merged = arr1.concat(arr2);
console.log(merged); // [1,2,3,4]
console.log(arr1); // [1,2]`}>

```js
let arr1 = [1, 2];
let arr2 = [3, 4];
let merged = arr1.concat(arr2);
console.log(merged); // [1,2,3,4]
console.log(arr1); // [1,2]
```

</CodeBlock>

### join

- **Functionality:** Joins all elements of an array into a string with a specified separator
- **Input:** Separator (optional, defaults to comma)
- **Output:** String
- **Modifies Original Array:** No

Example:

<CodeBlock title="Javascript" raw={`let words = ["Hello", "World"];
console.log(words.join(" ")); // "Hello World"
console.log(words.join(",")); // "Hello,World"`}>

```js
let words = ["Hello", "World"];
console.log(words.join(" ")); // "Hello World"
console.log(words.join(",")); // "Hello,World"
```

</CodeBlock>

### flat

- **Functionality:** Flattens nested arrays up to a specified depth
- **Input:** Depth (optional, defaults to 1)
- **Output:** New array
- **Modifies Original Array:** No

Example:

<CodeBlock title="Javascript" raw={`let arr = [1, [2, [3, 4]]];
console.log(arr.flat()); // [1, 2, [3,4]]
console.log(arr.flat(2)); // [1, 2, 3, 4]"`}>

```js
let arr = [1, [2, [3, 4]]];
console.log(arr.flat()); // [1, 2, [3,4]]
console.log(arr.flat(2)); // [1, 2, 3, 4]
```

</CodeBlock>

### flatMap

- **Functionality:** Combines map() and flat() with depth 1
- **Input:** Callback
- **Output:** New array
- **Modifies Original Array:** No

Example:

<CodeBlock title="Javascript" raw={`let arr = [1, 2, 3];
let result = arr.flatMap(n => [n, n*2]);
console.log(result); // [1,2,2,4,3,6]`}>

```js
let arr = [1, 2, 3];
let result = arr.flatMap((n) => [n, n * 2]);
console.log(result); // [1,2,2,4,3,6]
```

</CodeBlock>
